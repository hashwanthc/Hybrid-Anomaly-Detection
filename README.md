# Hybrid Anomaly Detection System

## 📌 Overview

The **Hybrid Anomaly Detection System** is a machine learning-based project designed to identify anomalous patterns in data. It combines multiple detection approaches to analyze data and help distinguish normal behavior from potentially anomalous activity.

The project includes machine learning components, an autoencoder-based model, and supporting frontend components for the application.

## 🎯 Objectives

- Detect anomalous patterns in data using machine learning.
- Explore multiple anomaly detection techniques.
- Use an autoencoder model to support anomaly detection.
- Generate and analyze model outputs.
- Provide a foundation for further experimentation with anomaly detection.

- **Machine Learning:** Scikit-learn, depending on the implementation
- **Deep Learning:** TensorFlow/Keras, depending on the implementation

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

Replace the URL and repository name with your actual GitHub repository details.

### 2. Create a Virtual Environment

```bash
python -m venv p4env
```

Activate it on Windows:

```bash
p4env\Scripts\activate
```

On Linux or macOS:

```bash
source p4env/bin/activate
```

### 3. Install Dependencies

If the repository contains a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

If it does not, install the dependencies required by the project's Python files after checking their imports. The exact dependency list needs to be verified against the implementation.

### 4. Prepare the Dataset

Place the required dataset in the expected location used by the Python scripts.

**Important:** CSV files are excluded by the current `.gitignore` rule `*.csv`. If the application requires a dataset that is not included in the repository, obtain it separately and place it in the appropriate directory.

### 5. Run the Project

Check the Python scripts to determine the correct entry point and execution order.

For example, if `person4_final.py` is the main application script:

```bash
python person4_final.py
```

The exact command may differ depending on the project's implementation and dependencies.
